# 图文配对提取 操作指南

> 工具文件：`pair_extractor.html`（Chrome / Edge 打开，无需安装）
> 任务编号：T1
> 数据规模：约十数本高价值书籍（来自 T0 筛选结果）

---

## 任务背景

经过 T0 筛选，我们得到了一批「高价值」书籍——其中存在**单人全图动作照片 + 文字描述**的配对内容。

由于 OCR 和排版解析的限制，图片与文字之间的对应关系无法自动提取，需要人工逐条整理。

**你的任务**：阅读书籍 MD 原文，将符合条件的**动作图像**与对应的**完整文字描述**手动配对，形成结构化的图文对，供后续模型训练使用。

---

## 界面说明

打开工具、选择书籍文件夹后，界面分为左右两栏：

```
┌─────────────────────┬──────────────────────┐
│   左栏：MD 原文预览  │   右栏：图文配对区   │
│                     │                      │
│  完整书籍内容        │  你整理出的配对列表  │
│  （文字 + 图片）     │  （图像 + 文本描述） │
│                     │                      │
│  底部：位置跳转滑块  │                      │
└─────────────────────┴──────────────────────┘
```

两栏宽度可拖动中间分隔条调整。

## 核心操作

### 添加一条配对

1. 在**左栏**滚动阅读 MD 原文，找到包含**人物动作图像**的位置
2. 图片下方有一个 **「＋ 添加」** 按钮，点击它
3. 该图片自动出现在**右栏**，附带一个空白文本框
4. 在文本框中填入你认为与该图对应的文字描述

```
点击前：                     点击后右栏新增：
┌──────────────┐             ┌────────────────────────────┐
│  [图片]      │             │ #1                    删除  │
│              │  →→→        │ ┌──────┐ ┌──────────────┐  │
│  [＋ 添加]   │             │ │ 图片 │ │ 文本描述...  │  │
└──────────────┘             │ └──────┘ └──────────────┘  │
                             └────────────────────────────┘
```

---

### 填写文本描述（重要 — 请仔细阅读）

文本框填入后变为**绿色边框**，行也变绿，代表该条配对已完成。

#### 摘录原则：完整摘录动作条目全文

**核心要求**：你要摘录的不只是"步骤"，而是图片所属的**整个动作条目的全部描述**。

一个完整的动作条目通常包含以下部分（按书中结构，不是每本书都有全部，但出现了就要纳入）：

| 应摘录的内容 | 示例 |
|---|---|
| 动作名称 | "哑铃弯举"、"俯卧撑" |
| 简介/原理 | "主要锻炼肱二头肌…" |
| 起始姿势 | "双脚与肩同宽，双手正握哑铃…" |
| 操作步骤 | "屈肘将哑铃上举至肩部…" |
| 动作要点/技巧 | "保持肘部固定不动…" |
| 注意事项/常见错误 | "避免借助身体惯性甩动…" |

**常见错误（务必避免）**：
- 只摘了操作步骤，丢掉了前面的简介和后面的注意事项
- 只摘了一个小标题下的一句话，没有包含同属一个动作的其他段落
- 自己改写或概括了原文

#### 摘录定位方法

1. 找到图片在 MD 原文中的位置
2. 从图片**往上**找到最近的**大标题**（通常是动作名称），这就是条目的起点
3. 从该标题**往下**读，包含所有连续的子段落（要点、步骤、注意事项等），直到遇到一个**明显属于另一个不同动作**的新大标题为止
4. 将这个范围内的所有文字摘录填入

#### 具体要求

- **直接摘录原文**：从书中复制粘贴文字，严禁自行改写、概括或添加原文中没有的词语
- **长度不少于 30 字**：如果找不到 30 字以上的完整描述，说明该图不适合配对，跳过
- **去除格式符号**：摘录时去掉 `#`、`*`、列表编号等 Markdown 格式符号，让文本成为通顺的自然语言
- **不含无关内容**：与图中动作无关的段落（如其他动作、营养建议、训练计划安排）不要纳入

#### 示例对比

**错误做法**（只摘了步骤）：
> 屈膝下蹲，大腿与地面平行后起身还原。

**正确做法**（完整动作条目）：
> 杠铃深蹲。主要锻炼股四头肌、臀大肌及核心稳定肌群。起始姿势：双脚与肩同宽，脚尖略外展，杠铃置于上背斜方肌上，双手正握杠铃略宽于肩。动作过程：吸气，屈膝屈髋下蹲，保持腰背挺直，膝盖方向与脚尖一致，下蹲至大腿与地面平行或略低于平行，在最低点短暂停留后，呼气，蹬地起身还原。要点：全程保持核心收紧，避免膝盖内扣；下蹲速度略慢于起身速度。注意事项：初学者应在深蹲架内进行，使用较轻重量掌握动作模式后再逐步加重。

### 处理多图同动作（合并配对）

书中经常用**多张图**展示同一个动作的不同阶段（起始位→动作过程→结束位）。这些图应当**合并为一条配对**，共享同一段文字描述。

#### 判断多图是否属于同一动作

以下条件**全部满足**才算同一动作：
1. 同一个人（或同一示范者）
2. 同一个**具体**动作（如"哑铃弯举"，不是泛指"手臂训练"）
3. 属于该动作的连续阶段（起始→过程→结束）

以下情况**不是**同一动作（应分开配对）：
- 动作名称不同（如"深蹲"和"硬拉"是两个动作）
- 使用的器械不同
- 只是同大类（如都是"腿部训练"但具体动作不同）
- 不同的人在做动作

#### 操作方法

对属于同一动作的多张图，将它们添加到同一条配对中：
- 每条配对最多**4 张图**
- 文本描述填写一次，覆盖整组图片

```
正确：                           错误：
┌─────────────────────────┐     ┌─────────────────┐
│ #1                      │     │ #1 [图A] 深蹲…  │
│ [图A] [图B] [图C]       │     │ #2 [图B] 深蹲…  │  ← 相同内容重复3次
│ 杠铃深蹲。主要锻炼…     │     │ #3 [图C] 深蹲…  │
└─────────────────────────┘     └─────────────────┘
```

## 什么样的图值得配对（5 条判定标准）

一张图必须**同时满足以下全部条件**才应添加配对：

| # | 条件 | 说明 |
|---|---|---|
| 1 | 图中有人物 | 真人照片、卡通插画、线稿、黑白示意图均可 |
| 2 | 人物在做明确的身体动作 | 如深蹲、举重、伸展、跑步等健身/体能动作，而非静止站立 |
| 3 | 人物全身出镜 | 不是肌肉局部特写、上/下半身截断、脸部特写 |
| 4 | 图像完整 | 不是被截断的半截图 |
| 5 | 图像主体是人物动作 | 不是以文字、表格、图表为主的示意图 |

**明确不添加的情况：**

- 纯文字页面
- 肌肉/骨骼/解剖结构图（无完整人物做动作）
- 局部特写（只有手臂、只有腿、只有脸）
- 书籍封面、版权页、目录页
- 人物只是静止站立，未做任何运动动作
- 多人合影、比赛现场照（非教学示范）
- 图像不完整或严重模糊
- 装饰性小图标、分割线图案

## 图文一致性自检

每完成一条配对，花 3 秒钟自检：

1. **图文对应**：文本描述的动作确实是图中展示的动作（不是相邻的另一个动作）
2. **摘录完整**：包含了该动作条目的全部内容（名称+描述+步骤+注意事项），而非只有片段
3. **无关内容已剔除**：没有混入其他动作的描述

如果对应关系不确定，**跳过该图**，不强行配对。

## 标注进度与保存

### 实时缓存
工具会**自动将标注内容保存到浏览器缓存**（localStorage）。
关闭页面后重新打开，选择同一文件夹，工具会提示：

```
发现上次标注缓存（N 条配对），是否恢复？
[恢复]  [忽略]
```

点击**「恢复」**即可接续上次进度，无需重头开始。

## 质量标准速查表

| 维度 | 合格 | 不合格 |
|---|---|---|
| 图片选择 | 全身出镜 + 做明确动作 | 局部特写 / 静止站立 / 解剖图 |
| 文本完整性 | 包含动作名称 + 描述 + 步骤 + 注意事项 | 只有一两句步骤 |
| 文本来源 | 直接摘录原文 | 自行概括或改写 |
| 文本长度 | ≥ 30 字 | 太短，信息不足 |
| 多图处理 | 同一动作合并为一条（≤4 图） | 同一动作拆成多条重复配对 |
| 图文对应 | 文本就是描述图中那个动作 | 文本是相邻另一个动作的描述 |

## 注意事项

| 事项 | 说明 |
|------|------|
| **浏览器** | Chrome 90+ 或 Edge 90+，Safari 可能无法选择文件夹 |
| **文件夹结构** | 文件夹内须含 `.md` 文件和 `images/` 子目录，否则图片无法显示 |
| **每次一本书** | 每次工具只加载一本书；标注完下载 JSON，返回后选下一本 |
| **质量优先** | 专注于有价值的图文配对，宁可少标也不要标错 |
| **文本可直接复制** | 推荐从左栏直接复制原文粘贴，减少手动输入错误 |

## 常见问题

**Q: 图片显示为灰色空白？**
A: 确认文件夹内有 `images/` 子目录，且 MD 文件和 `images/` 在同一层级。图片使用懒加载，滚动到图片位置附近时才会加载，稍等片刻即可显示。

**Q: 点了「＋ 添加」没反应？**
A: 图片可能仍在加载中（灰色占位符），等图片完全显示后再点击按钮。

**Q: 同一张图被我错误添加了两次怎么办？**
A: 在右侧找到多余的那行，点击「删除」即可。

**Q: 进度条百分比和我看到的位置不符？**
A: 进度条基于文档总行数计算，图片密集区域视觉上占的高度更大，但对应的行数比例可能较小，属正常现象。

**Q: 缓存恢复后图片显示为空白？**
A: 缓存只保存文件名和文字，图片需要重新加载文件夹才能显示。选择同一文件夹后点「恢复」即可。

**Q: 怎么判断哪些文字属于同一个动作条目？**
A: 从图片往上找到最近的动作名称标题，再往下读，直到看到下一个明显不同的动作标题为止。中间的所有内容（包括"要点""注意""变化形式"等小标题）都属于同一条目。

**Q: 文本太长怎么办？**
A: 不限制上限，完整摘录比截断更重要。只要是与该动作相关的完整描述，不管多长都应该纳入。
