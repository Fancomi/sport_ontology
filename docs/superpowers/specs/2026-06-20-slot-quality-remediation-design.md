# 槽位质量整改设计：黑名单门禁 + 严格审核 + 重跑

## 背景

首轮 14 槽位扩充（body_position / tempo / limb_state）重跑了 6236 个 CN 文件，但抽查发现新键大量误标。实测误标率：

| 新键 | 误标率 | 主要失败模式 |
|---|---|---|
| `body_position` | 11% | 碎裂（弓步｜姿势）、泛词（姿势/姿态/保持）、修饰词游离（新月式姿态｜站立） |
| `tempo` | 29% | 整句误标（动作节奏平稳且控制良好）、泛词/力学评价（稳定/平稳/控制）、跨槽 |
| `limb_state` | 29% | 64% 无肢体部位词——节奏词（控制节奏36/平稳）、纯部位（双手）、轨迹词漏入 |

根因：**值是自由原文片段时，没有任何门禁挡住"模型把不属于该槽的词圈进去"**。limb_state 尤其退化成垃圾桶，580 处里只有 208 处是真·非主导肢体姿态。

## 目标

不损失 LLM 泛化能力（**不用白名单**）的前提下，通过**黑名单 + 结构锚点 + 严格审核**提升新键精度，并补正面引导提升召回，重跑全量。

**v2 修订（2026-06-22，经召回审计后定）：**
- `limb_state` **拆除**——实测召回天花板仅 2%、边界难定（接触/支撑/节奏词反复漏入）。从 14 键降为 **13 键**。
- 原 limb_state 承载的"非主导肢体姿态"（双手置于头侧、另一条腿屈膝、对侧手臂向上伸直）**归入 `posture_alignment`**（旧自由文本键，放宽定义吸收单侧/非主导肢体配置）。
- 新键只剩 **body_position、tempo**，且补正面引导提召回。
- **召回达标线**：body_position ≥90%（天花板 77%，实测 91% 达标）、tempo ≥55%（下调；天花板 29%、低频键，"爆发性/暂停"等边界词天然难标，40 条富集实测 56%）；精度仍守规则层违规 = 0。

## 铁律（沿用）

对存量 category_3，只增删 `[key:value]` 方括号，绝不改汉字。去括号后逐字相等（`reslot_utils.invariant_ok`）。审核剥离坏标 = 去括号保留裸词，同样守此铁律。

## posture_alignment 放宽定义（吸收原 limb_state 内容）

```
posture_alignment = 整体对齐/姿态 + 单侧或非主导肢体的配置姿态
  原职责：腰背挺直、双脚与肩同宽（整体轴线对齐）
  新增吸收：双手置于头侧、另一条腿屈膝、对侧手臂向上伸直（单侧/非主导肢体姿态）
是自由文本旧键，不受新键门禁约束。
```

## 三层防御（黑名单制，保泛化）

### 第 1 层：写入时硬门禁（2_3，代码层，确定性）

`reslot_utils.py` 新增三类确定性规则。命中即剥离该标注（裸词留句中，文字不动），**不限制合法值泛化，只挡明确污染**。

**规则 1 — 跨槽黑名单（按目标槽，命中即拒）**
```python
TEMPO_BLACKLIST        = {"稳定","平稳","受控","协调","流畅","控制良好","身体稳定"}
LIMB_STATE_BLACKLIST   = {"离心","向心","上升","下降","顶峰收缩","水平","旋转",
                          "控制节奏","节奏","轻快","缓慢","快速","爆发力","停顿","静态",
                          "发力","蹬伸","推","拉","保持稳定"}
BODY_POSITION_BLACKLIST= {"姿势","姿态","保持","动作"}
```
判定：value 命中对应槽黑名单（精确等于 OR 作为子串包含黑名单词）→ 剥离。

**规则 2 — limb_state 结构锚点（硬性，两条都须满足）**
```python
LIMB_PARTS = {"腿","臂","手","脚","膝","肘","肩","髋","踝","腕","颈","背"}
PURE_PART  = {"双手","单手","双脚","单脚","双腿","单腿","双臂","背部","手"}  # 纯部位无姿态
# limb_state value 必须：(a) 含至少一个部位词；(b) 不等于纯部位词（须带姿态动作）
```
(a) 挡掉无部位的节奏/状态词（实测 64%）；(b) 挡掉 `双手`/`单手` 这类"光有部位、没姿态"的（实测 77 处）。合格示例须形如「部位+姿态」：`另一条腿屈膝`、`双手置于头侧`。

**规则 3 — 整句拒绝**：任一新键 value 字符数 ≥ 8 → 剥离（合法档位词 ≤4，部位姿态短语一般 ≤7；整句误标全 ≥8）。

统一入口 `new_slot_value_ok(slot, value) -> bool`，2_3 写入前、2_4 审核共用。

### 第 2 层：prompt 收紧（2_3_reslot_cn.md，黑名单写进 prompt）

在现有 prompt 加 4 块：

1. **黑名单内联**：tempo 禁力学评价词；limb_state 禁轨迹/节奏/发力词、必须含部位词；body_position 禁泛词（姿势/姿态/保持/动作）。
2. **短语取整规则**：value 必须圈完整语义短语，禁止只圈一截、禁止修饰词游离括号外；不确定不标。
3. **反面教材**（本轮真实坏例）：`[limb_state:控制节奏]`、`[limb_state:双手]`、`[tempo:动作节奏平稳且控制良好]`、`[tempo:动态]`、`[body_position:保持]`、`左膝着地的低弓步[body_position:姿势]`。
4. **limb_state 重定义**（见上节）。

### 第 3 层：2_4 审核升级（能删坏标 + 多轮 + 阈值）

`2_4_audit_reslot.py` 从"只报告"升级为把关者：

1. **规则层剥离**（确定性，复用 `new_slot_value_ok`）：命中黑名单/结构/超长 → 剥离该标注，原地写回。
2. **LLM 语义层剥离**（治"值合法但圈错"）：句子+新键标注喂 LLM，按裁决矩阵判碎裂/修饰词游离/语义不符 → 剥离。
3. 两层只删括号不动汉字，`invariant_ok` 全程守。
4. **多轮回路**：小样本重跑 2_3 → 2_4 审核出违规率 → >阈值则调 prompt/黑名单 → 再跑，循环至达标才放行全量。
5. **产出** `reslot_audit_v2.json`：每键违规分类计数 + 样例。

## 验收阈值

| 指标 | 阈值 |
|---|---|
| 规则层违规率（黑名单/结构/超长命中） | **全量 = 0%**（确定性必须挡净） |
| LLM 层语义违规率（碎裂/圈错） | **抽样 ≤ 2%** |
| 去括号逐字相等 | 100%（铁律） |

达不到不算过，继续迭代 prompt/黑名单。

## 执行流程

```
1. 回退数据：重拉 6505 定版 CN(11键纯净) ← http://10.52.101.140:8555/datas/muscle_wiki/
   （清掉所有坏新键数据；EN 已 kill，本体聚合产物已 git checkout 回 HEAD）
2. 改代码(TDD):
   · reslot_utils: new_slot_value_ok（黑名单+结构锚点+超长）+ 单测
   · 2_3 prompt: 黑名单+短语取整+反面教材+limb_state 重定义
   · 2_3 写入门禁: 调用 new_slot_value_ok，不过即剥离
   · 2_4: 规则层剥离 + LLM 语义层剥离 + 多轮 + 报告
   · 并发 -w 32×4端口=128（benchmark 已验证零错误）
3. 小样本多轮: 20条 → 2_4审核 → 违规率 → 调 prompt/黑名单 → 循环至 规则层0% / LLM层≤2%
4. 全量重跑 2_3(32并发) → 2_4 全量审核 → reslot_audit_v2.json
5. 验收达标 → 收敛闭词表(仅统计参考,不门禁) → 提交
```

## 范围外（YAGNI）

- 不重建本体（5_enrich/5_1/5_2）——等三键数据干净后另起。
- 不动 EN 同步——CN 干净后再跑 2_2（EN 已 kill，无残留）。
- 不用白名单门禁——会损失 LLM 泛化（躺/趴/平躺等合法新词应放行）。

## 测试与验证

- `new_slot_value_ok` 单测：黑名单命中拒、结构锚点（limb_state 无部位词拒）、超长拒、合法值放行。
- 2_4 剥离单测：坏标被剥离且 `invariant_ok` 仍成立、好标保留。
- 重跑后全量断言：规则层违规 0、50 条抽样去括号逐字相等。
- 验收门：`reslot_audit_v2.json` 三键违规率达阈值。
